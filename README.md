# 基于FPGA的OLED面板驱动时序与图像数据传输系统
针对中小尺寸OLED面板高刷新率驱动需求，基于Xilinx Artix-7 FPGA设计实现OLED驱动时序控制与图像数据传输链路，解决跨时钟域数据丢包、驱动时序裕量不足导致的画面闪烁、显示异常等问题。

## 项目背景
OLED面板驱动需要高精度的行场同步时序与高速像素数据传输，时钟域不匹配、时序收敛差会导致画面花屏、丢帧。本项目实现完整的数字驱动前端原型，包含数据接口、时序控制、跨域缓冲三大模块，可用于OLED驱动原理验证与显示效果测试。

## 核心功能
- 支持SPI模式的像素数据输入，最高50MHz数据时钟
- 多行场同步时序FSM状态机，生成VSYNC/HSYNC/DE标准显示时序
- 异步FIFO跨时钟域缓冲，匹配输入时钟与面板驱动时钟速率差
- 驱动时序物理层验证，支持Setup/Hold时间裕量分析与优化

## 技术方案与难点
1. **跨时钟域数据稳定传输**
   - 控制信号采用双级触发器同步，消除亚稳态传播
   - 像素数据流采用异步FIFO+格雷码指针方案，深度256
   - 实时水位监测，防止数据溢出与读空

2. **高精度显示时序控制**
   - 三段式FSM状态机实现行扫描、场扫描、数据有效区精确控制
   - 时序参数可配置，适配不同分辨率与刷新率的OLED面板
   - 同步信号消隐区间参数化设计，兼容通用面板协议

3. **时序收敛与板级验证**
   - 全设计同步时序约束，关键路径逻辑重定时
   - 逻辑分析仪抓取驱动时序波形，量化Setup/Hold裕量
   - 连续72小时压力测试，零丢帧、无时序违规

## 性能指标
- 支持最大分辨率：1920×1080@60fps
- 像素数据吞吐率：40Mbps
- 时序裕量：Setup ≥ 2.3ns，Hold ≥ 1.8ns
- 连续运行丢帧率：0%
